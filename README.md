# nlp-translate

> OCR·번역 모델·Gradio 연동

## 프로젝트 개요

- 주제: OCR·번역 모델·Gradio 연동
- 형태: Jupyter Notebook 기반 실험
- 저장소: https://github.com/ttony0321/nlp-translate
- 기본 브랜치: main
- 공개 범위: Public

## 주요 기능

- 번역 모델 학습
- OCR 문자 인식
- Gradio 추론 화면
- EDA·학습·서비스 코드 분리

## 기술 스택

- Python
- Jupyter Notebook

## 프로젝트 구조

- `NLP_EDA.ipynb`
- `README.md`
- `gradio.py`
- `ocr.py`
- `train.py`

## 실행 방법

- Jupyter 실행 환경 구성
- 데이터 경로 설정
- 실행 순서: NLP_EDA.ipynb

## 핵심 구현

- 분석 과정과 모델 실험을 Notebook 단위로 분리
- 데이터 탐색부터 결과 확인까지의 흐름 구성

## 개선 과제

- 의존성 버전 고정
- 환경변수 기반 경로·설정 관리
- 대표 평가 지표와 결과 그래프 문서화
